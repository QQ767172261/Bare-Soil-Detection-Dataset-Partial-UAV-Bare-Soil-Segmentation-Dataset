### 数据集摘要
专门用于**裸土(bare‑soil)** 目标检测任务，图像主要为地表航拍影像，只标注裸土这一类地物，可直接导出YOLO等主流格式用于模型训练。适合土地裸露监测、水土流失分析、地表覆盖物识别、遥感/无人机视觉算法研究。数据集作者自定义版本预处理、增强、图片数量需要访问原链接查看完整统计。

### 应用场景
✅ 航拍/遥感裸土区域提取
✅ 水土流失、土地沙化风险监测
✅ 城市裸土扬尘监管
✅ 深度学习目标检测实验、毕业设计
